# 제6회 Uni-DTHON 데이터톤 · 1팀

열화상 이미지와 센서로 현재 관측 시점의 배터리 열폭주 단계 1~6을 분류합니다.
현재 후보는 **CatBoost v1**이며, 후보 제출 파일명은 **`submission_catboost_v1.csv`**입니다. 최종 평가 파일은 대회 사이트에서 별도로 확정합니다.

## 모델과 특징

제공 베이스라인 v7의 특징 33개와 전처리를 유지하고, 분류기를 로지스틱 회귀에서 CatBoost로 교체한 비교 실험입니다.

| 항목 | 구성 |
|---|---|
| 현재 시점 | `relative_time_s` 1개 |
| 센서 | `meas_v`, `meas_a`, `meas_t1`, `meas_t2`, `meas_p` 5개 |
| 이미지 | 회색조 밝기의 평균·표준편차·최댓값·95/99 분위수·밝기 0.8 이상 픽셀 비율 6개 |
| 과거 특징 | 센서 5개와 이미지 최댓값·99 분위수의 과거 30초 평균·최댓값·차이 21개 |
| 합계 | 33개 |

이미지 밝기는 0~1로 변환합니다. 밝기 통계와 고정 임계값 비율은 가색 이미지의 특징이며, 실제 온도로 변환한 값이 아닙니다.

과거 특징은 같은 `experiment_id`에서 현재 시점까지의 관측만 사용합니다. 평균·최댓값의 구간은 `(현재 시점 − 30초, 현재 시점]`이며, 차이는 현재 값에서 30초 이전 또는 그 시점의 마지막 관측값을 뺍니다. 미래 관측이나 실험 전체 통계는 사용하지 않습니다.

## 학습과 검증

| 항목 | 설정 |
|---|---|
| 분류기 | `CatBoostClassifier`, `MultiClass` |
| 주요 설정 | 600 trees, depth 6, learning rate 0.05, L2 leaf regularization 3.0 |
| 난수 시드 | 42 |
| 클래스 가중치 | 없음 |
| 학습 실행 | CPU, 학습 스레드 4개 |
| 이미지 처리 | 기본 작업자 4개 |
| 전처리 | 학습 데이터의 중앙값으로 결측 대체 → `StandardScaler` |
| 교차검증 | Train의 `experiment_id` 기준 5-fold `GroupKFold` |
| 평가 지표 | 라벨 1~6의 Macro F1 |
| 저장 모델 | Train만으로 학습 |

각 교차검증 fold에서 전처리는 해당 fold의 학습 부분에만 fit합니다. 저장 모델의 전처리와 분류기도 Train으로만 fit하며, 제공 Validation은 평가에 사용합니다. 이 실험은 Validation에 따른 early stopping이나 설정 선택을 하지 않았습니다.

사전학습 모델과 외부 데이터는 사용하지 않습니다. 제공 서버에 RTX 5080 16GB가 있으나, 이번 CatBoost 실험의 학습·추론은 CPU에서 수행했습니다.

## 확인한 성능

| 모델 | Train 5-fold CV Macro F1 | Validation Macro F1 | Public Macro F1 |
|---|---:|---:|---:|
| 베이스라인 v7 · 로지스틱 회귀 · 가중치 없음 | 0.8033 | 0.6778 | 0.8517 |
| CatBoost v1 · 가중치 없음 | **0.8732 ± 0.0300** | **0.7505** | **0.8827502081** |

CV는 fold별 점수의 평균 ± 표준편차입니다. Private 점수는 아직 확인하지 않았습니다. Public 점수로 최종 성능을 확정하지 않습니다.

제공 서버에서 공식 제출 검사 전체를 통과했습니다.

| 검사 | 확인 결과 |
|---|---|

빈 이미지 검사는 이미지가 예측에 영향을 주는지 확인한 결과입니다. 8.43%는 정확도나 이미지 결합으로 얻은 성능 향상률이 아닙니다.

## 추론 재현

저장소 루트에서 실행합니다. 필요한 패키지는 제공 서버의 대회 가상환경에서 설치합니다.

```bash
python -m pip install -r requirements.txt
python test.py --input <입력_CSV> --image_root <이미지_폴더> --output <출력_CSV>
```

필수 세 인자만으로 실행할 수 있습니다. 기본 가중치 경로는 `test.py`가 있는 폴더 기준 `weights/model.joblib`입니다. 다른 가중치는 `--model <가중치_경로>`로 지정합니다.

출력은 `sample_id,label` 두 열이며, 입력의 `sample_id`와 행 순서를 유지하고 `label`을 1~6 정수로 저장합니다. 추론은 입력 CSV의 이미지와 과거 특징을 다시 계산하고, 저장된 전처리와 모델을 적용합니다. Test 통계 fit이나 전체 Test 예측·특징 캐시는 사용하지 않습니다.

## 학습 재현

`<데이터_루트>`에는 공식 `train/`, `validation/` 폴더가 있어야 합니다. 학습·추론은 대회 제공 서버에서 실행합니다.

```bash
python -u train.py --data_dir <데이터_루트>
```

기본 출력은 `weights/model.joblib`와 `weights/model.metrics.json`입니다. 같은 경로에 재학습하면 기존 파일을 덮어쓰므로, 제출한 후보 가중치는 먼저 별도 보관합니다.
